# Contribution Guidelines
Thanks for your interest in contributing! This document explains how you can contribute to this project in a variety of 
ways.

> [!IMPORTANT]
> By participating, you agree to follow the [Code of Conduct](CODE_OF_CONDUCT.md).

## Ways to Contribute
- **Report Bugs:** Is something broken? Submit an [issue](../issues/new).
- **Suggest a Feature:** Think something should be added to the project? Submit an [issue](../issues/new).
- **Improve Documentation:** Something not worded correctly? Is documentation unclear? Submit a [pull request](../pulls)
  with your proposed changes.
- **Help Others:** Answer questions in [issues](../issues) and [discussions](../discussions).

## Pull Requests
### Submitting a PR
1. Push your branch to your fork.
2. Open a pull request against the `main` branch.
3. Fill out the PR template and include short descriptions of any changes. If necessary, a short explanation about the
   change can also be included.

### Checklist
- [ ] Commit messages follow [Conventional Commits](https://www.conventionalcommits.org/)
- [ ] Commit history is linear
- [ ] Unit tests added to any code changes
- [ ] All tests pass
- [ ] Documentation updated, if applicable
