# Support
## Getting Help
- [**Documentation**](README.md) - showcases how to install and use this project in your own repository.
- [**Discussions**](../discussions) - for discussions about the project (questions, brainstorming, comments, etc.).
- [**Issues**](../issues) - for submitting reports related to the project (i.e. bug fixes, feature requests).

## Before You Ask
- Search existing issues and/or discussions.
- Check the FAQ.
- Include version and steps to reproduce, if applicable.

## Do NOT
- File public issues or create discussions for security vulnerabilities. To report a vulnerability, see 
  [SECURITY.md](SECURITY.md).
- Email a Community Moderator and/or project author for assistance. You may utilize [issues](../issues) and
  [discussions](../discussions) for this.
